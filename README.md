# Boryviter

Boryviter is a multi-object detector and tracker trained on birds. Birds were chosen as the target domain because they are well-documented by large and diverse datasets, making them a useful test case for building a robust computer vision system. They are also a practical target for field testing.
Boryviter is the first component of a larger project: a small UGV-style robot capable of detecting and following a bird. 
The final system is intended to run on a compact platform, using a lightweight model suitable for deployment in the field.
